# Implementación de Filtros Espaciales para el Preprocesamiento de Imágenes

## Descripción del Proyecto

Este proyecto consiste en el desarrollo de un **programa en C++** que realiza el **preprocesamiento de imágenes digitales** utilizando filtros espaciales, específicamente mediante la técnica de **convolución**. Los filtros espaciales se aplican para realizar diversas tareas de procesamiento de imágenes, como la **detección de bordes**, el **suavizado**, el **realce de detalles** y el **ajuste de contraste**.

### Funcionalidades Implementadas

El programa implementa varios filtros espaciales comunes utilizados en procesamiento de imágenes, tales como:

1. **Detección de Bordes**: Utiliza filtros como el de Sobel para identificar los bordes en una imagen, lo que es útil en tareas de segmentación o reconocimiento de objetos.
   
2. **Suavizado (Blur)**: Aplica un filtro de media o un filtro gaussiano para reducir el ruido en la imagen, haciendo que los detalles sean menos evidentes pero aumentando la calidad visual en entornos ruidosos.
   
3. **Realce de Imágenes**: Emplea filtros de realce como el filtro de Laplace para aumentar los detalles visibles y destacar ciertas características en la imagen.
   
4. **Ajuste de Contraste**: Modifica el contraste de la imagen para mejorar la visibilidad de ciertas áreas o detalles, utilizando métodos como la ecualización del histograma.
